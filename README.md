## 📖 Description
The **String Analyzer in C** is a beginner-friendly project developed to demonstrate fundamental concepts of C programming such as arrays, loops, conditional statements, and string manipulation.

This program takes a string input from the user and performs multiple analyses, including:
- Counting the total number of characters  
- Identifying vowels and consonants  
- Detecting digits and special characters  

The project focuses on strengthening core programming logic and providing hands-on experience in problem-solving using C.
